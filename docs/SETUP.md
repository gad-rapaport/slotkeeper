# Setup

## Requirements

Docker with Compose v2; PowerShell 7 for `scripts/ops.ps1` (optional); Node.js 24 for development and the
simulation script. Ports `127.0.0.1:8103` (demo) and `127.0.0.1:54103` (development database).

## Environment

`.env` from [.env.example](../.env.example), generated by `./scripts/ops.ps1 setup`.

| Variable                                                                        | Meaning                                                                   |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `POSTGRES_PASSWORD`                                                             | Database password (letters and digits)                                    |
| `SEED_ADMIN_PASSWORD`, `SEED_MEMBER_PASSWORD`                                   | Demo passwords, 12+ characters                                            |
| `BOOKING_RATE_LIMIT_PER_MINUTE`                                                 | Booking creations per user per minute (default 30)                        |
| `LOGIN_RATE_LIMIT_PER_MINUTE`                                                   | Sign-ins per address and account per minute (default 10; E2E runs set 60) |
| `MAX_ACTIVE_BOOKINGS_PER_USER`, `BOOKING_HORIZON_DAYS`, `IDEMPOTENCY_TTL_HOURS` | Rules (20, 60, 24)                                                        |
| `DATABASE_URL`, `DEV_ORIGIN`, `OPENAPI_PATH`, `TEST_DATABASE_URL`               | Local development only                                                    |

## Demo stack

```powershell
./scripts/ops.ps1 setup
```

Without PowerShell: copy `.env.example` to `.env`, replace every placeholder, then
`docker compose up -d --build --wait` and `docker compose --profile tools run --rm seed`.

## Development

```powershell
npm ci
./scripts/ops.ps1 dev-db
# add DATABASE_URL, DEV_ORIGIN, OPENAPI_PATH, TEST_DATABASE_URL to .env (see .env.example)
npm run db:seed
npm run dev:server     # 127.0.0.1:3103
npm run dev:web        # 127.0.0.1:5183
```

Migrations: [server/migrations](../server/migrations), checksum-verified, applied at start-up under an
advisory lock (same runner as Fieldline).
